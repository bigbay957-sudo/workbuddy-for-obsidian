# WorkBuddy for Obsidian 0.8.3

本版本是一次功能密集更新（覆盖 0.8.0 – 0.8.3）：重点增强了多媒体输入、模型选择、快捷指令和界面精简，让侧边栏轻量会话更接近 WorkBuddy 本体的体验。

## 本次更新

### 0.8.3

- 模型选择器打开页面即在左下角显示，不再需要先发送一条消息。
- 未拿到模型列表前显示占位状态（默认模型 / 连接中… / 连接失败），悬浮提示说明当前状态。
- 打开任务页自动预热连接 WorkBuddy，尽早拉取可用模型列表；失败静默，发送消息时自动重试。

### 0.8.2

- 人设（常驻指令）入口移至右上角设置按钮的二级菜单，移除输入区人设按钮；`#` 快捷编辑保留。
- 模型选择器顶部新增“Auto（自动选择）”选项，与 WorkBuddy 的 auto 模式对齐。
- 移除“资料包”功能，界面更精简。
- 移除“撤销修改”功能。

### 0.8.1

- 输入区右下角新增“快捷”按钮，弹出深色垂直指令面板。
- 内置 5 个通用指令：正式润色、口语润色、一键翻译、代码审查、笔记整理。
- 支持在设置页自定义指令，增删改立即生效并标“自定义”角标。
- 点击指令自动拼接当前编辑器选区发送；无选区时只发指令。

### 0.8.0

- 发送键在工作时变为红色停止按钮，停止后在回答处标记“已停止”。
- 回答正文中出现的 Vault 文件名自动转为可点击链接，直接打开对应文件。
- 新增主题色设置，立即生效并保留。
- 过滤 CLI 启动期间的 banner 文本，不再误显示为 AI 回复。
- 支持在输入框粘贴或拖入图片，直接随消息发送给模型分析。
- 新增常驻指令（人设）：输入 `#` 编辑，每次发送自动拼接。
- 回答支持选取部分内容复制，新增“复制选中”操作。
- 左下角新增模型选择器：自动读取可用模型列表，可手动切换，切换不重启 CLI。

## 安装

下载 `workbuddy-for-obsidian-0.8.3.zip`，解压到 `<你的知识库>/.obsidian/plugins/workbuddy-for-obsidian/`，然后在 Obsidian 的第三方插件设置中启用。已安装旧版本的用户覆盖 `main.js`、`manifest.json`、`styles.css` 三个文件即可，`data.json` 配置无需改动。

## 前置条件

需要 Obsidian 桌面版 1.7.2+，以及已经安装并登录的 WorkBuddy CLI：

```bash
npm install -g @tencent-ai/codebuddy-code
codebuddy
```

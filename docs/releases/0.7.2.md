# WorkBuddy for Obsidian 0.7.2

这是首个 GitHub 公开发布版本，包含从 0.1.0 到 0.7.2 的完整功能。

## 本次更新

- “@ 添加资料”列表首项新增“上传本地文件”。
- 支持一次选择多个电脑文件。
- 文件复制到 Vault 的 `WorkBuddy/Uploads/` 后自动引用，不移动或修改原文件。
- 同名文件自动增加序号，单个文件上限 200MB。

## 核心能力

- 最多 5 个独立任务页与自动恢复。
- 选区引用、Diff 替换和安全撤销。
- 笔记/文件夹/标签/标题/PDF/图片强引用与来源追溯。
- 项目资料包、关联笔记推荐、历史搜索、回答收藏与完整导出。
- 通用工作模板和选区快捷处理。

## 安装

下载 `workbuddy-for-obsidian-0.7.2.zip`，解压到 `<你的知识库>/.obsidian/plugins/workbuddy-for-obsidian/`，然后在 Obsidian 的第三方插件设置中启用。

## 前置条件

需要 Obsidian 桌面版 1.7.2+，以及已经安装并登录的 WorkBuddy CLI：

```bash
npm install -g @tencent-ai/codebuddy-code
codebuddy
```

# WorkBuddy for Obsidian 0.8.4

本版本聚焦于模型选择器的细节打磨：让 Auto 默认行为更顺手、显示更稳定；并同步刷新了 README 截图，体现当前真实界面状态。

## 本次更新

### 模型选择器常显与默认 Auto

- 打开任务页即可在左下角看到模型下拉，未取得列表前显示 `Auto`、`连接中…`、`连接失败` 等占位，悬浮提示说明当前状态。
- 取得列表后默认仍选中 **Auto**，与 WorkBuddy 的 auto 模式对齐；用户手动选过的模型会被记住。
- 首次拉取到列表后，若 CLI 当前值不是 auto，会静默调用 `session/setConfigOption` 切到 auto；`setConfigOption` 新增 `silent` 参数，CLI 不接受 auto 时不打扰会话。

### 视觉与交互修复

- 模型下拉固定宽度（112px），不再随选项文字自适应变化而从窄变宽跳动。
- 按 `lowercase value` 去重，合并 CLI 偶尔返回的 `hy3` 与 `Hy3` 等仅大小写不同的重复条目。
- 移除模型选择器左侧多余的图标，按钮高度与相邻的 `@ 资料`、`关联资料` 按钮自然对齐。
- 选项文案 `Auto（自动选择）` 简化为 `Auto`。

### 文档

- 替换 `README.md` 截图，反映最新的 0.8.x 界面状态。
- 同步更新功能亮点与“多任务与聊天记录”段，删除已废弃的资料包/撤销修改描述，新增模型与人设段。

## 安装

下载 `workbuddy-for-obsidian-0.8.4.zip`，解压到 `<你的知识库>/.obsidian/plugins/workbuddy-for-obsidian/`，然后在 Obsidian 的第三方插件设置中启用。已安装旧版本的用户覆盖 `main.js`、`manifest.json`、`styles.css` 三个文件即可，`data.json` 配置无需改动。

## 前置条件

需要 Obsidian 桌面版 1.7.2+，以及已经安装并登录的 WorkBuddy CLI：

```bash
npm install -g @tencent-ai/codebuddy-code
codebuddy
```

# WorkBuddy for Obsidian 0.7.3

此版本将插件内置工作模板调整为通用模板，适用于不同职业、团队和项目场景。

## 本次更新

- 默认工作模板调整为会议纪要、内容润色、汇报提纲、案例总结和执行方案。
- 模板提示词不再预设特定行业，保留事实边界、结构化输出和可执行性要求。
- 项目资料包的示例名称改为通用项目表达。
- README、发布说明和测试样例同步采用通用场景。

## 安装

下载 `workbuddy-for-obsidian-0.7.3.zip`，解压到 `<你的知识库>/.obsidian/plugins/workbuddy-for-obsidian/`，然后在 Obsidian 的第三方插件设置中启用。

## 前置条件

需要 Obsidian 桌面版 1.7.2+，以及已经安装并登录的 WorkBuddy CLI：

```bash
npm install -g @tencent-ai/codebuddy-code
codebuddy
```
